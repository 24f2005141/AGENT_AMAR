# 👋 AGENT AMAR Vault

This Obsidian vault is the **control center and knowledge layer** for AGENT AMAR — an autonomous multi-agent email intelligence system.

➡️ **Start here: [[Agent Control Center]]**

## What this vault is for

1. Agent Control Center (dashboard)
2. Knowledge & memory management layer
3. Agent definitions and instructions
4. Workflow documentation
5. System rules and policies
6. Human-readable agent activity & debugging logs

## What this vault is NOT

It is **not** the application database. Real emails, tasks, deadlines, user activity, and notification history will live in a proper backend database. This vault holds knowledge, rules, prompts, and human-readable memory only.
