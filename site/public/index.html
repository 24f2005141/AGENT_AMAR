API Contract (Phase 12 / 13)

Interactive API Documentation

The AGENT AMAR backend is built with FastAPI & SQLite, providing frozen, deterministic REST endpoints for Gmail synchronization, multi-agent intelligence, reminders, and deadline monitoring.

Core Endpoints
POST /api/v1/gmail/sync
Phase 12 / 13 Standard

Trigger ONE incremental Gmail sync using the Gmail History API. Processes only newly added messages since the last successful sync. Idempotent and safe against concurrent runs.

cURL Request Example Copy 
curl -X POST "http://192.168.1.10:8000/api/v1/gmail/sync"

Quickstart & Launch Guide

Run the full stack in minutes across Windows, Android tablets, and mobile devices.

1

Start FastAPI Server

Python 3.11+ • Bound to 0.0.0.0:8000

Run the server listening on all network interfaces so physical tablets/phones on your local Wi-Fi can connect directly: 

cd backend
python run_server.py
# Or: uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
check_circle Swagger UI available at: http://localhost:8000/docs
2

Launch Flutter App

Android Tablet / Phone / Desktop

Deploy the debug APK to your connected Android tablet or emulator: 

cd frontend
flutter run -d 
# Base URL configured to: http://192.168.1.10:8000
