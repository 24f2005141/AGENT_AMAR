# Laya integration study for Agent AMAR

Source audited: [Laya repository](https://github.com/NandhaKishorM/laya), commit `573e5b62696ba441230cd6be71d593331b5d23af`; package `laya==0.3.5`. The project is Apache-2.0 licensed. Its public API evaluates a state plus batched typed `choice`, `noul`, and `score` questions without generating prose. This is architecturally similar to Jev's typed-decision API, but **the repository does not establish that Laya has the same weights, training data, calibration, accuracy, or latency as Jev**. We therefore treat it as a separate provider and benchmark it independently.

The repository exposes three checkpoint families: an English ModernBERT-large model (421M parameters, 512-token context), a multilingual mmBERT-base model (322M, 1024-token context), and a typed-decisions ModernBERT-large model (421M, 1024-token context). Its router can select a checkpoint by language. AMAR currently pins the [typed-decisions checkpoint](https://huggingface.co/convaiinnovations/laya-typed-decisions) because its API matches AMAR's batched structured questions; this does **not** guarantee good email classification. The model file is about 843 MB and is downloaded/lazy-loaded on first use. The default is CPU inference, with a single process-wide loaded model and lock. The model is not called for deterministic-only mail.

AMAR presents the same compact email state and bounded questions to Jev and Laya, validates returned categories/actions/deadline types, and applies the same confidence gates. Unresolved fields fall back to Gemini then Groq. Reply drafting stays on the generative providers because Laya produces no prose. The Profile screen stores the mode choice on the backend, so API processing and background Gmail sync agree after restarts.

The author's advertised millisecond timings are on a T4 GPU and must not be extrapolated to this CPU-only Ryzen 5 7520U laptop. The live AMAR sample measured a warm Laya shared decision around 85 seconds p50 and 0/5 category decisions accepted at AMAR's threshold; the cold call took about 159 seconds. Laya had no external inference fee, but the fallback still incurs network cost and latency. The [quantitative comparison](AI_MODE_COMPARISON_2026-09-23.md) contains raw scope, token and pricing caveats. For this machine, Jev remains the practical default typed-decision candidate; Laya is experimental, particularly with AMAR's 15-way category choice and small evaluation sample.
